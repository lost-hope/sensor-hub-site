WLED Sensor Hub

A central WLED usermod that turns sensor readings from independent provider usermods into MQTT (with Home Assistant discovery), the /json API and the web UI Info tab — plus consumer usermods that bind those readings straight into effects, brightness and color, live.

Hub Repo 23 Providers 2 Consumers Built for WLED

How it fits together

One usermod owns the bus. Everything else either feeds it or reads from it — no provider ever talks to MQTT/JSON/HA directly, and no consumer ever needs to know which physical chip a reading came from.

Providers

Read one piece of hardware (an I2C chip, a GPIO pin, ...) and push readings into the hub.

→

Sensor Hub

Owns MQTT/HA discovery, the JSON API and the Info tab. Sensors register at compile time, attach at runtime — no fixed limit.

Sensor Hub

Exposes readings by name (getValueByName()) or by quantity (getValue(type)).

→

Consumers

Read the hub and drive an effect, a color, brightness — a bespoke effect, or a generic live binding.

The Hub

sensor-hub

Compile-time sensor slot registration (no fixed sensor limit), an open string-identified measurement type system, MQTT + Home Assistant discovery, the JSON API, Info tab display with per-quantity unit conversion.

Sensor Providers

Each provider owns exactly one piece of hardware and knows nothing about MQTT, JSON, or Home Assistant — that's the hub's job.

Consumer Usermods

These don't provide sensors — they read the hub and drive WLED itself.

particle-tilt-effect

Adds a new WLED effect, "Accel Tilt": a particle-system box that tilts with a real accelerometer reading, instead of a canned animation.

sensor-fx-binder

Binds live sensor readings to any existing effect's speed/intensity/custom sliders, brightness, color or checkboxes — generically, no bespoke effect required.

Getting started

  1. Clone/symlink sensor-hub and whichever provider(s) match your hardware next to your WLED checkout.
  2. Add them to custom_usermods in platformio_override.ini:
custom_usermods =
  ${env:esp32dev.custom_usermods}
  sensor-hub = symlink://../sensor-hub
  sensor-hub-bme280-provider = symlink://../sensor-hub-bme280-provider
  1. Build and flash. Configure each provider's pins/I2C in its own Settings page — sensors appear in MQTT, the Info tab and /json/state automatically once attached.
  2. Optionally add sensor-fx-binder to bind a live reading straight into an effect.

Full wiring, settings and MQTT/HA discovery details are documented in each repo's own readme — start with sensor-hub.
